# 考研数学真题研究社 (Kaoyan Math Hub)

这是一个面向考研学子的数学真题研究与刷题平台，旨在通过数据可视化、清晰的考点树和沉浸式的刷题界面，提升考研数学的复习效率。

## ✨ 核心特色

- **📚 历年真题墙**：采用直观的网格流式排版，收录了历年数学真题。试卷年份一目了然，方便整套做题或浏览。
- **🌲 考点大纲分类**：左侧边栏提供精确到三级考点的知识树结构，基于大纲进行划分。点击任意层级的标题，即可一键高亮真题墙中的相关题目，或开启专项刷题。
- **📝 沉浸式刷题体验**：
  - 点击“刷题”或任意真题，进入沉浸式刷题模态框。
  - 支持隐藏题号与难度盲练，也支持直接显示原题的年份题号。
  - 一键切换查看答案和名师视频解析。
- **📊 学习数据可视化**：引入了 Chart.js 雷达图与柱状图，深入分析各个题型模块（如：一元函数微分、矩阵、随机变量等）的分值分布与你的刷题熟练度，精准找到薄弱环节。
- **💾 本地离线缓存**：你的刷题记录、掌握程度等数据自动存储在浏览器本地（Local Storage），无需繁琐登录，随时随地保持你的复习进度。

## 🚀 如何运行

本项目是一个纯前端静态项目，依赖于本地缓存和本地数据文件。

1. **克隆项目到本地：**
   ```bash
   git clone https://github.com/XixiGod7/kaoyan-Math.git
   cd kaoyan-Math
   ```
2. **启动本地服务器：**
   由于跨域和本地文件读取限制，建议使用任意静态服务器运行。如果你安装了 Python：
   ```bash
   python -m http.server 8000
   ```
3. **访问网站：**
   打开浏览器，访问 `http://localhost:8000` 即可开始刷题！

## 📁 核心文件结构

- `index.html` / `index.css`: 项目主界面结构与自定义样式，采用响应式布局。
- `app.js`: 页面主要交互逻辑、知识树渲染、刷题模态框控制与状态缓存。
- `data.js`: 核心真题数据结构，包含历年试卷结构与每个题目的元信息（年份、考点、难度等）。
- `crawler.py` / `download_images.py`: 数据采集工具链，用于获取试题图片和关联数据。
