# 考研数学真题研究社 (Kaoyan Math Hub)

这是一个面向考研学子的数学真题研究与刷题平台，旨在通过数据可视化、清晰的考点树和沉浸式的刷题界面，提升考研数学的复习效率。

## ✨ 核心特色

- **📚 历年真题墙**：采用直观的网格流式排版，收录了历年数学真题。试卷年份一目了然，方便整套做题或浏览。
- **🌲 考点大纲分类**：左侧边栏提供精确到三级考点的知识树结构，基于大纲进行划分。点击任意层级的标题，即可一键高亮真题墙中的相关题目，或开启专项刷题。
- **📝 沉浸式刷题体验**：
  - 点击“刷题”或任意真题，进入沉浸式刷题模态框。
  - 支持隐藏题号与难度盲练，也支持直接显示原题的年份题号。
  - 一键切换查看答案和名师视频解析。
- **📊 学习数据可视化**：引入了 Chart.js 雷达图与柱状图，深入分析各个题型模块（如：一元函数微分、矩阵、随机变量等）的分值分布与你的刷题熟练度，精准找到薄弱环节。
- **💾 本地离线环境**：所有外部依赖均已内置，你的刷题记录、掌握程度等数据自动存储在浏览器本地（Local Storage），断网也能完美复习。

## 🚀 如何运行

本项目现已全面升级为**纯粹离线版本**，所有的框架与资源（如 Tabler, jQuery, Chart.js）均已内置在 `assets/libs` 中。没有任何外部网络依赖，甚至无需搭建本地服务器！

1. **下载或克隆项目到本地：**
   您可以直接从本仓库的 Releases 页面下载最新的压缩包，解压后进入文件夹。
2. **一键开启：**
   - **Windows 用户**：直接双击目录下的 `一键双击运行.bat` 文件即可自动在浏览器中打开。
   - **其他系统用户**：直接使用任意现代浏览器（如 Chrome, Edge）拖拽打开根目录下的 `index.html` 文件。

*(注：为避免体积过大，仓库源码中并未包含原生的整套试卷 PDF 扫描件。但这完全不影响您的使用，所有的刷题展示均由内置的高清题干图片及数据结构支持完成！)*

## 📁 核心文件结构

- `index.html` / `index.css`: 项目主界面结构与自定义样式，采用响应式布局。
- `app.js`: 页面主要交互逻辑、知识树渲染、刷题模态框控制与状态缓存。
- `data.js` / `data_crawled.js`: 核心真题数据结构，包含历年试卷结构与每个题目的元信息（年份、考点、难度等）。
- `assets/libs/`: 离线所需的全部前端依赖库。
- `crawler.py` / `download_images.py`: 数据采集工具链，供二次开发者抓取与整理试题图片时使用。
